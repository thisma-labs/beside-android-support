Android Installation & Setup

Beside for Android is distributed as an official, cryptographically signed release APK (Beside-v0.1.1-Android-arm64.apk, 32.54 MB) for direct installation on Android phones and tablets.

Download Signed APK (v0.1.1)

How to Install & Update the Signed APK

  1. Download Beside-v0.1.1-Android-arm64.apk on your Android phone or tablet.
  2. Tap the downloaded file in your browser's download shelf or in your device's Files / Downloads manager.
  3. If prompted by Android security, toggle on Allow from this source (Install unknown apps) for your browser or file manager, then tap Install (or Update).

Seamless In-Place Upgrades & Data Continuity

When updating to a newer Beside version, simply install the new APK over the existing installation. Do not uninstall the old app. Because all official Beside releases are signed with our consistent cryptographic release certificate, Android's Package Manager performs an in-place upgrade, preserving your paired devices in TrustStore, private keys in Keystore, transfer history, and Beside Pro activation.

Sideloading Safety & Android Warnings: Android displays a default warning ("File might be harmful") for any direct APK download outside the Play Store. You can verify the integrity of our APK using standard checksum tools before opening it.

Verifying APK SHA-256 Checksum

sha256sum Beside-v0.1.1-Android-arm64.apk

Android System Requirements

  • Operating System: Android 8.0 Oreo (API 26) through Android 16.
  • Processor Architecture: 64-bit ARM (arm64-v8a).
  • Memory (RAM): Bounded 64 KB streaming buffer — transfers multi-gigabyte video files with flat memory usage.
  • Network: Local Wi-Fi network or Android Mobile Hotspot. No mobile data plan or internet connection is required for file or text transfers.

Local Network & System Permissions

Beside requests only the minimum Android permissions needed for local peer discovery and file streaming. It never requests access to Contacts, Microphone, Camera Roll read-all, or GPS Location:

Wi-Fi Multicast Lock

ACCESS_WIFI_STATE and CHANGE_WIFI_MULTICAST_STATE allow Beside to receive local mDNS peer discovery packets (_beside._tcp.local.) over Wi-Fi.

Notifications (Android 13+)

POST_NOTIFICATIONS displays incoming transfer approval alerts and live foreground transfer progress.

Foreground Transfer Service

FOREGROUND_SERVICE and FOREGROUND_SERVICE_DATA_SYNC prevent Android from killing active transfers when you switch apps.

Storage Access Framework (SAF)

Files save to Downloads/Beside by default. Beside Pro users can select any custom directory using Android's scoped Storage Access Framework.

Device Discovery & Connection Troubleshooting

1. Same Wi-Fi Router or Android Mobile Hotspot

Connect both your Android device and Windows PC to the same Wi-Fi network. If you are on a public Wi-Fi with Client Isolation, turn on your Android phone's Mobile Hotspot and connect your PC directly to it.

2. Automatic Cellular Interface Filtering

You do not need to disable 4G/5G mobile data. Beside automatically filters out cellular interfaces (rmnet, ccmni, pdp) so local discovery and TLS transfers bind exclusively to your Wi-Fi or Hotspot interface.

3. Automatic Wi-Fi Reconnection Recovery

When your phone disconnects and reconnects to Wi-Fi, Beside's connectivity monitor automatically refreshes the Wi-Fi MulticastLock and restarts mDNS discovery so your phone reappears on your PC without restarting the app.

4. Connect by IP or QR Code

If multicast is blocked on your router, tap Connect by IP / QR to scan the QR code shown on your peer device or enter its IP:port manually.

Sending & Receiving Files on Android

  • Android System Share Sheet: Share photos, videos, documents, or text directly from Google Photos, Gallery, Files, or any browser by tapping Share → Beside (ACTION_SEND & ACTION_SEND_MULTIPLE).
  • Default Save Location: Received files are stored in Internal Storage/Download/Beside.
  • Automatic Gallery Indexing: Received photos and videos are automatically scanned via MediaScannerConnection.scanFile so they appear immediately in Google Photos and your system Gallery.
  • Collision-Safe Auto-Rename: Beside never overwrites existing files; duplicate filenames are renamed automatically (e.g., photo (1).jpg).
6

Device Pairing & Security

  • Mutual TLS 1.3 & Pinned Fingerprints: Every session uses TLS 1.3 with pinned X.509 SPKI SHA-256 certificate fingerprints.
  • 8-Digit SAS Verification Code: Confirm the 8-digit code matches on both screens during first-time pairing.
  • Android Keystore AES-256-GCM: Your device's private identity key is encrypted at rest using hardware-backed Android Keystore storage.
  • Auto-Accept (Beside Pro): Enable Auto-Accept in Settings to receive files from paired devices without manual confirmation prompts.

Background Activity & Battery Optimization

To keep your Android device discoverable when Beside is in the background or the screen is off, enable Background Visibility in Beside Settings and configure your device's battery optimization settings:

Xiaomi / Redmi / POCO (MIUI & HyperOS)

Open App info → Autostart (enable), then tap Battery saver → No restrictions.

Samsung Galaxy (One UI)

Open App info → Battery → Unrestricted, and remove Beside from Sleeping apps in Device Care.

OPPO / OnePlus / Realme (ColorOS)

Open App info → Battery usage and enable Allow background activity & Allow auto-launch.

Google Pixel / Stock Android

Open App info → App battery usage and select Unrestricted.

Frequently Asked Questions (Mobile)

Does Beside use mobile data when transferring files?

No. All transfers happen strictly over your local Wi-Fi or local hotspot connection with zero mobile data consumption.

Can my Free Android phone receive large files from a Beside Pro PC?

Yes. Receiving from a Pro device is always unrestricted. Furthermore, one Beside Pro license covers up to 3 personal devices across Windows and Android.

Where are received text snippets stored on Android?

Incoming text messages are displayed in-app and in notifications with a one-tap Copy action. They are never saved unencrypted to disk.

Known Issues & Solutions (Mobile)

Issue: Phone disappears from Windows device list after the screen locks

Solution: Enable Background Visibility in Beside Settings and set Battery Optimization to Unrestricted / No restrictions (Section 7).

Issue: "App not installed as package conflicts with an existing package"

Solution: Uninstall any older debug/test build first, then install the official signed release APK.

Issue: Custom Save Folder permission lost after Android OS update

Solution: Open Settings → Save Location in Beside and re-select your preferred folder via the Android folder picker.
